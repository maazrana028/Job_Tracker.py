# Job_Tracker.py
This small program using python has been made on VS Code which uses tools such as SQLite 3 and the Tkinter to produce a GUI interface where individuals can keep track of their Job Applications by entering various options such as Company name, Role, Status of the application made, When was it sent and Has follow up been made. 

Step 1: Set Up the Project
Install Python from python.org.

Install the required libraries:

bash
Copy
pip install tkinter
Open VS Code and create a new Python file, e.g., job_tracker.py.

Step 2: Design the Database
We’ll use SQLite to store job application details. Create a table to store:

Job ID (primary key)

Company name

Job role

Application status (e.g., Applied, Interviewed, Rejected)

Application date

Follow-up date

Step 3: Build the GUI Using Tkinter
We’ll create a simple GUI with the following components:

Input fields for company, role, status, application date, and follow-up date.

Buttons to add, update, and delete job applications.

A table to display all job applications.

Step 5: Run the Application
Save the file as job_tracker.py.

Run the script
